# ⚔️ Jujutsu Fighting

[🇧🇷 Português](README.md) | 🇺🇸 **English** | [🇯🇵 日本語](README.ja.md)

Academic fan game developed with **Construct 3**, inspired by the **Battle of the Strongest** arc from *Jujutsu Kaisen*.

The project recreates the battle between **Gojo and Sukuna** as a 2D fighting experience, featuring mechanics, abilities and visual elements inspired by the series.

## 🎮 About the Game

Jujutsu Fighting was developed during the first term of the **Analysis and Systems Development** program as one of the first academic projects of the course.

The project was created to apply introductory concepts of programming logic and game development through an interactive experience built with Construct 3.

## ✨ Features

- 2D combat
- Playable characters inspired by Jujutsu Kaisen
- Special abilities
- Combat mechanics developed using Construct 3's event system
- Scenarios and visual elements inspired by the series
- Interface designed specifically for the project

## 🛠️ Tools and Technologies

- Construct 3
- HTML
- CSS
