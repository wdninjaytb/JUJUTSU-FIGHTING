# ⚔️ Jujutsu Fighting

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇯🇵 **日本語**

**Construct 3**を使用して制作した大学のファンゲームで、『呪術廻戦』の**五条悟と両面宿儺の戦い**にインスパイアされています。

このプロジェクトでは、作品を参考にしたメカニクス、能力、ビジュアル要素を取り入れ、**五条悟と両面宿儺**の戦いを2D格闘ゲームとして再現しました。

## 🎮 ゲームについて

Jujutsu Fightingは、**システム分析・開発（ADS）**コースの最初の学期に、初期の大学プロジェクトの一つとして制作しました。

Construct 3を使用したインタラクティブなゲーム制作を通して、プログラミングロジックやゲーム開発の基礎を実践することを目的としています。

## ✨ 主な特徴

- 2D格闘システム
- 『呪術廻戦』にインスパイアされたプレイアブルキャラクター
- 特殊能力
- Construct 3のイベントシステムを使用した戦闘システム
- 作品を参考にしたステージやビジュアル要素
- プロジェクト用に制作したインターフェース

## 🛠️ 使用ツール・技術

- Construct 3
- HTML
- CSS

## 📁 プロジェクトファイル

このリポジトリにある`.c3p`ファイルは、**Construct 3**で開くことができます。

## 🎓 制作背景

**システム分析・開発（ADS）**コースの最初の学期の大学課題として制作したプロジェクトです。

このゲームは学習および大学での活動を目的として制作した非営利のファンプロジェクトであり、『呪術廻戦』およびその権利者とは公式な関係はありません。
